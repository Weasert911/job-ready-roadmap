# job-ready-roadmap

Learning and work log for the **Aug 14, 2026 → Jan 1, 2027** Rust + TypeScript systems/devtooling engineering sprint.

## Target

Become a credible junior/intern/contract-level **Rust + TypeScript systems/devtooling engineer**:

- Strong Rust fundamentals → async → Axum → PostgreSQL
- TypeScript / Node.js / React fundamentals
- Linux, Docker, Git, CI/CD, testing, deployment basics
- 1 flagship developer tool + 3–8 real OSS contributions
- Polished GitHub, resume, portfolio, demo video

1. No tutorial hell — rebuild from memory.
