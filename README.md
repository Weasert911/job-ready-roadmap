# job-ready-roadmap

Project-driven competency and work log for the **Aug 14, 2026 -> Jan 1, 2027** Rust + TypeScript systems/devtooling engineering sprint.

## Target

Become a credible junior/intern/contract-level **systems + developer tooling engineer**, Rust-first and TypeScript-second, with the foundation to build complete full-stack and Tauri desktop software:

- Strong Rust fundamentals → async → Axum → PostgreSQL
- TypeScript / Node.js / React fundamentals
- Linux, Docker, Git, CI/CD, testing, deployment basics
- 1 flagship developer tool + 3–8 real OSS contributions
- Polished GitHub, resume, portfolio, demo video

## Weekly rhythm

| Metric | Target |
| --- | --- |
| Coding | 15–25 focused hours |
| Rust | Every week |
| Shipped work | ≥ 1 meaningful deliverable |
| Documentation | ≥ 1 meaningful update |

Sunday = weekly deadline. School comes first when necessary.

## Rules

1. Every topic produces a proportionate project.
2. Learn -> close the resource -> rebuild -> break -> fix -> build -> explain.
3. A checkbox requires understanding, independent implementation, a working project, and explanation.
4. AI can tutor, debug, and review; unexplained AI code is not evidence.
5. Topic projects prove competency; only a few composition projects become portfolio work.
6. One flagship project. Real OSS. Solid fundamentals.

## Evidence Flow

```text
Topic -> focused project -> Sunday PASS/FAIL -> project archive
      -> combined system -> production practices -> selected portfolio work
```

The roadmap is not optimized for course completion. It is optimized for independently entering unfamiliar code, understanding it, solving a real problem, and shipping working software.
