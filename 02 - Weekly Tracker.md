## Sunday Procedure

1. List every topic attempted this week, including unfinished and failed topics.
2. Run each project and its relevant tests/checks from a clean starting point.
3. Make one meaningful modification without reopening the tutorial.
4. Explain the problem, mechanism, decisions, alternatives, and failure modes aloud or in writing.
5. Complete one topic evaluation block per topic.
6. Mark `PASS` only when all four gates are `YES`; otherwise record `FAIL` and a concrete remediation.
7. Update the matching checkbox in `01 - Skills.md` and row in `03 - Project Archive.md`.
8. Review the week's composition project separately; topic passes do not automatically make the larger system good.
