## Daily Loop

Work on one selected topic at a time:

```text
Learn -> close resource -> rebuild from memory -> break it -> fix it
-> build the named project -> explain it
```

At the end of a session, update only its status and `Next action`. Watching or copying alone is not progress.

## Sunday Check

For every attempted topic, answer:

```text
Can I build the core without help? YES / NO
Can I explain how and why it works? YES / NO
Does the project work? YES / NO
```

Three YES answers = `PASS`. Any NO = `FAIL` and the topic stays unchecked. On PASS:

1. Check the topic below.
2. Add one row to Completed Projects.
3. Clear This Week and choose the next realistic work.

## Rules

1. One active topic at a time.
2. Build before consuming another resource.
3. Use AI to explain, debug, and review, but keep no important code you cannot explain.
4. Tiny projects prove skills; do not polish all of them.
5. Reuse passed skills in weekly composition projects.
6. A checkbox means you can build, explain, and run the project independently.
